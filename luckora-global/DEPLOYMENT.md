# Luckora Deployment Guide

Luckora MVP is a Next.js app for the first public AI Personality Test launch.
This guide covers production deployment, analytics, domain setup, SEO
submission, and final checks.

## 1. Deployment Steps

Recommended provider: Vercel.

1. Push the latest Luckora code to a Git repository.
2. Import the project in Vercel.
3. Set the project root to `luckora-global` if the repository root contains
   other files.
4. Use the default build command:
   ```bash
   npm run build
   ```
5. Use the default output generated by Next.js.
6. Deploy and open the production URL.

Cloudflare Pages is possible, but a standard Next.js app usually needs a
Next-compatible Cloudflare adapter such as OpenNext for Cloudflare or the
current Cloudflare Pages Next.js integration. Vercel is the lowest-risk first
launch path.

## 2. Environment Variables

Create production environment variables from `.env.example`.

```bash
NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX
```

`NEXT_PUBLIC_GA_ID` is optional. If it is empty, the website still works and no
Google Analytics script is loaded.

Do not commit real secrets or private keys. The current MVP does not require any
server-side secrets.

## 3. Domain Binding

Target production domain:

```text
https://luckora.online
```

In the deployment provider:

1. Add `luckora.online` as a custom domain.
2. Add `www.luckora.online` if you want the `www` version.
3. Follow the provider DNS instructions.
4. In Spaceship DNS, add the required records.
5. Wait for DNS propagation.
6. Confirm HTTPS is active.
7. Make sure one canonical host is used. The current SEO config uses
   `https://luckora.online`.

## 4. Google Search Console

1. Open Google Search Console.
2. Add a Domain property for `luckora.online`.
3. Verify ownership through DNS TXT record.
4. Submit the sitemap:
   ```text
   https://luckora.online/sitemap.xml
   ```
5. Use URL Inspection for:
   ```text
   https://luckora.online/
   https://luckora.online/tests
   https://luckora.online/tests/personality-test
   ```
6. Request indexing after the production site is live.

## 5. GA4 Setup

1. Create a Google Analytics 4 property.
2. Create a Web data stream for `https://luckora.online`.
3. Copy the Measurement ID, for example `G-XXXXXXXXXX`.
4. Add it as `NEXT_PUBLIC_GA_ID` in the deployment provider.
5. Redeploy after setting the variable.
6. In GA4 DebugView or Realtime, confirm these events:
   ```text
   test_start
   test_complete
   result_view
   ```

## 6. SEO Files

Confirm these URLs work after deployment:

```text
https://luckora.online/robots.txt
https://luckora.online/sitemap.xml
https://luckora.online/opengraph-image
https://luckora.online/icon
```

The sitemap should include:

```text
/tests
/tests/personality-test
/personality/visionary-creator
/careers
/strengths
/guides
/reports
```

## 7. Launch Checklist

- [ ] `npm run build` passes.
- [ ] Production domain opens with HTTPS.
- [ ] `NEXT_PUBLIC_GA_ID` is configured if GA4 tracking is needed.
- [ ] Homepage loads correctly.
- [ ] `/tests/personality-test` opens correctly.
- [ ] A user can complete the 12-question test.
- [ ] `/report` shows the generated personality result.
- [ ] `test_start`, `test_complete`, and `result_view` are visible in GA4.
- [ ] `/robots.txt` returns the production sitemap URL.
- [ ] `/sitemap.xml` includes tests, hubs, and personality pages.
- [ ] Google Search Console property is verified.
- [ ] Sitemap is submitted to Google Search Console.

## 8. First Week Metrics

Watch these numbers during the first launch week:

- Homepage visits
- Test landing page visits
- `test_start` count
- `test_complete` count
- `result_view` count
- Test completion rate
- Search Console impressions
- Search Console indexed pages
- Top search queries
